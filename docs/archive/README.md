# Archive

This directory holds stale files: done plans, superseded proposals, dated review records and notes for outputs that the repo no longer keeps. They are history. Do not update them, and do not use them for current facts. Each current fact has one owner location outside this directory.

| Path | Content |
| --- | --- |
| `plans/` | Done plans (`docs/plans/` holds the open plans) |
| `esp32-firmware-proposal.md` | Phase 1 ASCII serial protocol proposal, superseded by micro-ROS (phase 2) |
| `pcb/review/` | Dated review records of the rev A board: `opus_prelim/`, `opus_final/`, `fable_final/` |
| `pcb/fab_README.md` | Notes for the committed rev A fab outputs. The repo no longer keeps fab outputs (`make pcb-fab` writes `build/fab/<BOARD>/`) |

Archived files keep their old paths in their text.
