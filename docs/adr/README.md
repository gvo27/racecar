# Architecture decision records (ADR)

An ADR records a decision that stays valid after its plan is done. Write an ADR before a change to an invariant (`docs/invariants.md`), the repo layout, or an interface (`docs/interfaces/`). Copy `0000-template.md` to `NNNN-<topic>.md` with the next number. Do not edit an accepted ADR. To change a decision, write a new ADR and set the old one to "Superseded by NNNN".
